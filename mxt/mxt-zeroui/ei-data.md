# Ei — Data Display Components

> Import: `import { ExAccount, ExHistory } from 'ei';`

| Component | Description |
|-----------|-------------|
| `ExAccount` | User account info display |
| `ExAnnounce` / `ExAnnounceView` | Announcement / detail view |
| `ExAuthority` | Permission management |
| `ExRegiment` | Multi-selector panel |
| `ExRelation` | Relation display |
| `ExService` | SubForm editor (I_API/I_JOB) |
| `ExTag` | Tag display |
| `ExTrackField` | Field comparison |
| `ExWizard` | Dual-form dependent search |
| `MyMenu` | User shortcut menu |
| `MyTodo` | My todo list |
