# Ex — Event System & Facade

> Source: `src/extension/library/entry.event.js` + `entry.facade.js` + `entry.fashion.js` + `entry.func.js`

## Event System

| Function | Purpose |
|----------|---------|
| `etPure(reference, key, fn)` | Pure event (no side effects) |
| `etParallel(reference, key, fns)` | Parallel event execution |
| `etSequence(reference, key, fns)` | Sequential event execution |
| `etUniform(reference, key, fn)` | Uniform event (standardized) |
| `rxChannel(reference, key)` | Reactive channel |
| `acCriteria(reference, key)` | Active criteria builder |

## Facade / Fashion / Func

| Module | File | Purpose |
|--------|------|---------|
| Facade | `web.js` | Render facade functions for standard component wrappers |
| Fashion | `op.js` | Operation handlers |
| Fashion | `romantic.js` | Batch operations |
| Func | utility | Utility functions for extension library |
