# i18n — Internationalization

> Source: `src/zither@em/` (lang alias)

## Language Control

| Function | Purpose |
|----------|---------|
| `Lg(key)` | Translate key from current Cab.json namespace |
| `fromPath(reference, ...path)` | Read from i18n/resource path |

## Resource Structure

```
src/cab/
  cn/                    # Chinese
    components/
      <module>/<page>/
        UI.json          # Page i18n strings
  en/                    # English
    components/
      <module>/<page>/
        UI.json
```

## Access Pattern

```jsx
@Ux.zero(Ux.rxEtat(require('./Cab.json'))
    .cab("UI")           // binds i18n namespace "UI"
    .to())
class PageComponent extends React.PureComponent {
    render() {
        const { $hoc } = this.props;
        // $hoc contains Lg function bound to Cab.json namespace
    }
}
```

## Merge Behavior

- Cab.json files are merged by namespace across `cn/` / `en/` directories
- `.cab("UI")` loads all UI.json entries for the current page
- `Z_LANGUAGE` env var controls active language (`cn` or `en`)
