# Ux — Async Helpers

> Source: `src/ux/interface.ajax.js`

| Function | Purpose |
|----------|---------|
| `asyncTrue(data)` | Resolve with true |
| `asyncData(data)` | Resolve with data |
| `callback(fn, reference)` | Wrap callback for safe execution |
| `asyncPromise(promiseFn)` | Wrap promise with error handling |
| `asyncValidate(reference)` | Async form validation wrapper |
| `asyncImage(uri)` | Async image loader |
| `asyncWrap(fn)` | Wrap async function |
| `rxEdict(reference, key)` | Reactive edict pattern |
| `responser(reference, key)` | Response handler builder |
