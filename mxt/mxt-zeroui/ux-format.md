# Ux — Formatting & HTML

> Source: `src/ux/unity.interface.*.js`

## Formatting

| Function | Purpose |
|----------|---------|
| `formatExpr(expr, data)` | Format expression with data |
| `formatNumber(value)` | Format number |
| `formatQuery(params)` | Format query params |
| `formatObject(obj)` | Format object for display |
| `formatCurrency(value)` | Format currency |
| `formatPercent(value)` | Format percentage |
| `formatTpl(tpl, data)` | Format template string |
| `formatDate(value, format)` | Format date |
| `formatNow(format)` | Format current time |

## HTML Helpers

| Function | Purpose |
|----------|---------|
| `htmlReadOnly(reference, key)` | Set field readonly |
| `htmlDisabled(reference, key)` | Set field disabled |
| `htmlErrorFocus(reference, key)` | Focus error field |
| `htmlErrorBlur(reference, key)` | Blur error field |
