# Ux — Math, Sorter & Random

> Source: `src/ux/unity.interface.*.js`

## Math

| Function | Purpose |
|----------|---------|
| `mathMultiplication(a, b)` | Multiply |
| `mathDivision(a, b)` | Divide |
| `mathSum(a, b)` | Sum |
| `mathDiscount(price, rate)` | Discount calculation |
| `mathSubtract(a, b)` | Subtract |

## Sorter

| Function | Purpose |
|----------|---------|
| `sorterObject(array, key)` | Sort objects by key |
| `sorterAsc(array, key)` | Sort ascending |
| `sorterAscFn(key)` | Ascending comparator function |
| `sorterAscT(array, key)` | Sort ascending (time) |
| `sorterAscTFn(key)` | Ascending time comparator |
| `sorterAscD(array, key)` | Sort ascending (date) |
| `sorterAscDFn(key)` | Ascending date comparator |
| `sorterDesc(array, key)` | Sort descending |
| `sorterDescFn(key)` | Descending comparator function |
| `sorterDescT(array, key)` | Sort descending (time) |
| `sorterDescTFn(key)` | Descending time comparator |
| `sorterDescD(array, key)` | Sort descending (date) |
| `sorterDescDFn(key)` | Descending date comparator |

## Random

| Function | Purpose |
|----------|---------|
| `randomUUID()` | Generate UUID |
| `randomString(length)` | Generate random string |
| `randomArray(array)` | Random array element |
| `randomInteger(min, max)` | Random integer in range |
