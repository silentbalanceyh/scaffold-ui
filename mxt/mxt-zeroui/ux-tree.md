# Ux — Tree Operations

> Source: `src/ux/unity.interface.*.js`

| Function | Purpose |
|----------|---------|
| `treeParentAllIn(keys, tree)` | All parents (inclusive) |
| `treeParentAll(keys, tree)` | All parents |
| `treeParent(key, tree)` | Direct parent |
| `treeChildren(key, tree)` | Direct children |
| `treeChildrenAll(key, tree)` | All descendants |
| `treeChildrenAllIn(key, tree)` | All descendants (inclusive) |
| `treeFlip(tree)` | Flip tree structure |
| `treeShared(left, right)` | Shared tree nodes |
| `toTreeConfig(config)` | Convert to tree config |
| `toTreeArray(tree)` | Flatten tree to array |
| `toTree(array, config)` | Build tree from array |
| `toTreeTextArray(tree)` | Tree to text array |
